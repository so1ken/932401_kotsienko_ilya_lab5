## Описание работы
В рамках лабораторной работы №5 добавлена интерактивность на страницу и реализовано сохранение состояния между перезагрузками.

### 1. Поиск элементов
Использованы все три метода поиска:
* `getElementById()` — секция книг (`#books`).
* `querySelector()` — кнопки управления, контейнер карточек, переключатель темы.
* `querySelectorAll()` — все существующие карточки книг на странице.

### 2. Манипуляции с DOM
* **Добавление книги** — `createElement` + `appendChild` создают новую карточку с обложкой, названием, автором и кнопкой «Прочитано».
* **Удаление книги** — `remove()` убирает последнюю карточку из контейнера.
* **Кнопка «Прочитано»** — при клике меняет текст (`textContent`) и переключает класс `.read` на карточке, подсвечивая её зелёным.

### 3. Интерактивность
* **Переключение темы** — кнопка «Тёмная тема» / «Светлая тема» добавляет/убирает класс `.dark-theme` на `<body>`, меняя CSS-переменные палитры.
* **Скрытие секции книг** — кнопка «Скрыть книги» / «Показать книги» переключает класс `.hidden-section`. Панель управления вынесена за пределы секции, чтобы кнопка не исчезала вместе с ней.
* **Обратная связь** — форма из ЛР №4 по-прежнему выводит данные в консоль.

### 4. Обработка ошибок
* Проверка существования элемента (`checkExists`) перед навешиванием обработчиков.
* Оборачивание всех обращений к `localStorage` в `try/catch`.
* Проверка наличия карточек перед удалением (иначе выводится `alert`).

### 5. Сохранение состояния (`localStorage`)
| Ключ | Что хранит |
|------|-----------|
| `bookworm_theme` | `'dark'` или `'light'` — выбранная тема |
| `bookworm_books` | JSON-массив добавленных книг (название, автор, статус) |
| `bookworm_books_hidden` | `'true'` / `'false'` — скрыта ли секция книг |

При загрузке страницы состояние восстанавливается: тема, видимость секции и список книг.

## Запуск
Открыть `index.html` в браузере. Все действия выполняются без перезагрузки страницы. Состояние сохраняется автоматически.

## Структура проекта
* `index.html` — основная разметка с подключённым скриптом
* `assets/css/style.css` — стили оформления, тёмная тема, анимации
* `assets/js/script.js` — логика на JavaScript (DOM + localStorage)
* `assets/images/` — изображения обложек и фото
